# 기본 자료 폴더

여기에 넣은 자료는 **이 앱을 쓰는 모든 선생님 화면**에 차시별 "기본 자료"로 나타나요.
올리면 1~2분 뒤 사이트에 자동으로 반영돼요. 파일 목록(`files.json`)은 GitHub Pages가 자동으로 채우니 건드리지 마세요.

## 폴더 이름 = 차시 번호

폴더 이름의 **첫 숫자**가 차시 번호예요. 아래는 모두 7차시로 들어가요.

```
materials/
├─ 07/
├─ 7차시/
└─ 07_재료가 다르면 달라질까/
```

## 폴더 안에 넣을 수 있는 것

| 넣는 것 | 앱에서 보이는 모습 |
|---|---|
| 슬라이드 이미지 (`슬라이드1.PNG`, `슬라이드2.PNG` …) | 한 묶음의 슬라이드, 파일 이름 순서대로 (1, 2, … 10) |
| 하위 폴더 안의 이미지 (`07/게임 슬라이드/…`) | 하위 폴더 이름을 제목으로 한 슬라이드 묶음 |
| PDF | 앱 안에서 바로 열리는 PDF |
| `links.txt` | 한 줄에 `제목 \| 주소`. 구글 슬라이드·캔바·유튜브는 화면 안에, 나머지는 새 창으로 열려요. 끝에 `\| 새창`을 붙이면 무조건 새 창으로 열려요. |
| 그 밖의 파일 (hwp, pptx, docx …) | 누르면 내려받는 첨부 파일 |

`links.txt` 예시

```
재료 비교 퀴즈 | https://docs.google.com/presentation/d/…/edit
어떤 재료일까? 게임 | https://www.tkbell.co.kr/…
```

## PPT 올리는 순서 (GitHub 웹에서)

1. PowerPoint에서 **파일 → 내보내기 → 파일 형식 변경 → JPEG(또는 PNG)** 를 고르고 "모든 슬라이드"로 저장해요. 슬라이드 이미지가 든 폴더가 생겨요.
2. 그 폴더 이름을 `07` 처럼 차시 번호로 바꿔요.
3. GitHub 저장소에서 `materials` 폴더로 들어가 **Add file → Upload files** 를 누르고, 그 폴더를 통째로 끌어다 놓아요.
4. 아래 **Commit changes** 를 누르면 끝. 1~2분 뒤 앱의 해당 차시에 "기본 자료"로 나타나요.

자료를 바꾸거나 지울 때는 GitHub에서 그 파일을 고치거나 지우면 돼요.

## 알아 두기

- 이 저장소는 공개라서 누구나 자료를 볼 수 있어요. 학생 사진이나 개인정보가 담긴 자료는 올리지 마세요.
- 파일 하나는 25MB까지 올릴 수 있어요. 슬라이드는 PNG보다 JPEG가 훨씬 가벼워요.
- 각 선생님은 자료 편집을 켜고 기본 자료를 **자기 컴퓨터에서만** 숨길 수 있어요.
